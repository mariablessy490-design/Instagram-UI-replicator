# Instagram-UI-replicator
## Instagram App – Project Documentation

###  Project Overview
Instagram is a social media application that allows users to share photos, videos, stories, and reels. Users can connect with friends, follow others, and communicate through messages.

###  Objectives
- To create a simple and user-friendly interface.
- To help users share photos and videos easily.
- To connect people through social media.
- To provide easy access to stories, reels, and messages.
- To improve the overall user experience.

###  Design Highlights
- Attractive and colourful UI design.
- Simple navigation and clean layout.
- Easy-to-use buttons and icons.
- Clear profile and post layouts.
- Consistent colours, typography, and spacing.

###  Features
- Home Feed: View posts from followed accounts.
- Stories: Share photos and videos for 24 hours.
- Reels: Watch and create short videos.
- Like & Comment: Interact with posts.
- Direct Messages: Chat with friends.
- Search & Explore: Discover new content and accounts.
- User Profile: Display profile details, followers, and posts.
- Notifications: Receive updates about likes, comments, and followers.
